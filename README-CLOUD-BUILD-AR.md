# تكسي مشوارك — معانا أريح

مشروع Android للزبون، جاهز للبناء السحابي.

## بناء APK من الهاتف باستخدام GitHub Actions

1. أنشئ حسابًا في GitHub من الهاتف.
2. أنشئ Repository جديدًا، ويفضل أن يكون Private.
3. ارفع محتويات هذا المجلد إلى الـRepository (وليس ملف ZIP نفسه).
4. افتح تبويب **Actions**.
5. اختر **Build Mashwarak Customer APK**.
6. اضغط **Run workflow**.
7. بعد نجاح البناء افتح نتيجة التشغيل، ثم قسم **Artifacts**.
8. نزّل `MashwarakCustomer-debug-apk.zip`، فك الضغط، وستجد `app-debug.apk`.
9. افتح APK على هاتف Android واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.
